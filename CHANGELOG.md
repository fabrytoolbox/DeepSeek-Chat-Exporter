# Changelog

## [1.0.0] - 2025-01-26

### Added
- Esportazione conversazioni DeepSeek (JSON) in HTML + TXT
- Estrazione messaggi in ordine cronologico (REQUEST + RESPONSE)
- Personalizzazione nomi utente/assistente
- Possibilita di saltare un ruolo (lasciando il nome vuoto)
- Validazione JSON prima dell'estrazione
- Filtro messaggi vuoti (solo simboli/spazi)
- Output HTML con tema scuro
- Output TXT per archivio
- Log su file con dettagli
- Controllo versione PowerShell 7
- Apertura automatica cartella output
